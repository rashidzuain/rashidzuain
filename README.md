## Proyectos

### [Robot Autómata](https://github.com/rashidzuain/robot-automata)

Laboratorio personal de robótica: un Arduino UNO para el control local y un servidor en la computadora que recibe la telemetría, la guarda y la muestra en un panel web que se actualiza cada segundo. Incluye un simulador para probar todo sin el robot conectado.

`Python` `FastAPI` `SQLite` `Arduino` `JavaScript`

### [Jarvis de escritorio](https://github.com/rashidzuain/jarvis-escritorio)

Asistente de IA que vive en la esquina del escritorio de Windows: un orbe 3D animado en WebGL, voz, memoria y acciones sobre la PC con permisos. El "cerebro" es un modelo local servido con Ollama u OpenJarvis.

`Electron` `JavaScript` `Three.js` `Whisper` `LLM local`

### [Automatización de videos y audio con n8n](https://github.com/rashidzuain/privacidad-proyect-one)

Dos recorridos conectados: crear videos con HeyGen a partir de datos de Airtable, y transcribir audio recibido por webhook. Los dos avisan por Slack. El repositorio incluye los workflows para importar en n8n, una guía de configuración y pruebas con servicios simulados.

`n8n` `Airtable` `HeyGen` `Groq` `Slack`

### [Ajedrez en Java](https://github.com/rashidzuain/ajedrez-java-poo)

Base de un ajedrez de consola para practicar programación orientada a objetos: interfaces, clases abstractas, herencia y excepciones propias.

`Java`

### En desarrollo: AgroVision IA
